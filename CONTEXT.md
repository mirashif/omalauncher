# OmaLauncher

OmaLauncher is a keyboard-first command palette for Omarchy that unifies applications, commands, menus, and shell features.

## Language

**OmaLauncher**:
The product and user-facing brand name.
_Avoid_: Omalauncher

**Compatibility namespace**:
The stable lowercase `omalauncher` identifier used by installed plugin IDs, persisted result IDs and state paths, integration metadata, and external configuration. It remains unchanged across the display-name rename.
_Avoid_: Using OmaLauncher as a technical identifier
