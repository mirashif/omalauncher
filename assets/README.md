# Assets

All product visuals are direct captures of the native Omalauncher surface on
Omarchy 4 at 1.25× monitor scale. Framed captures include 48 logical pixels of
padding on every side—60 rendered pixels at capture scale—so the wallpaper
frames the launcher without including unrelated desktop content. They contain
no bundled third-party artwork.

- `omalauncher-demo.gif` is a 15 fps, 970×692 hero loop showing Compact Mode,
  a `browser default` search, browser choices, and the Action Panel.
- `real-world-vscode-search.png` is an unedited, tightly framed live-session
  capture showing the installed Visual Studio Code application ranked first.
- `unified-search.png` shows an application and a related Omarchy command in
  the same `docker` result list.
- `command-context.png` shows `install spotify` resolving to Install › Service.
- `personalization.png` shows Visual Studio Code's structured Action Panel and
  its result management controls.
- `preview.png` is the previous Action Panel capture retained for historical
  comparison; the README no longer uses it.
