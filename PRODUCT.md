# Product

## Register

product

## Users

Omarchy users who prefer a keyboard-first workflow and need to find applications,
commands, shell features, plugins, calculations, and local files without remembering
where each action lives. They use the launcher in short, interruption-sensitive bursts
and expect the best action to be immediately understandable and executable.

## Product Purpose

OmaLauncher is a native command palette for Omarchy. It unifies discovery and action
across the desktop while preserving each source's safety and confirmation contracts.
Success means warm opens feel instantaneous, ranking is predictable, useful results
appear with minimal syntax, and optional features do not compromise the core launcher.

## Brand Personality

Fast, direct, and trustworthy. The product should feel native to Omarchy and borrow
the focused interaction quality of category-leading launchers such as Raycast without
imitating their platform-specific appearance.

## Anti-references

Avoid cluttered dashboards, decorative launcher chrome, modal-first workflows, hidden
execution behavior, unexplained dependencies, and interfaces that make keyboard users
leave the search flow to complete a simple action.

## Design Principles

1. Put the most likely answer first.
2. Prefer zero-configuration usefulness, then expose precise control.
3. Keep interaction and ranking predictable before personalization.
4. Preserve native Omarchy behavior and safe execution boundaries.
5. Keep optional work asynchronous so core search remains immediate.

## Accessibility & Inclusion

Preserve full keyboard and pointer access, explicit Qt accessibility names and roles,
high-contrast focus and shortcut states, readable theme-native text, and reduced-motion
friendly state changes. Do not rely on color alone to communicate state or priority.
